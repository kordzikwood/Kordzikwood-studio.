KORDZIKWOOD STUDIO 3.0 — DARMOWY PROTOTYP

Zawartość: index.html, manifest.webmanifest, sw.js, ikony.

INSTALACJA NA IPHONE / IPAD
1. Rozpakuj ZIP.
2. Umieść wszystkie pliki w katalogu darmowego hostingu statycznego z HTTPS (np. GitHub Pages).
3. Otwórz adres w Safari na iPhone/iPad, poczekaj na pierwsze załadowanie.
4. Udostępnij -> Dodaj do ekranu początkowego.
5. Po pierwszym załadowaniu aplikacja może działać offline; nie czyść danych Safari bez eksportu kopii.

DARMOWY HOSTING GITHUB PAGES (wymaga konta GitHub):
- utwórz publiczne repozytorium, dodaj pliki z ZIP do katalogu głównego,
- Settings -> Pages -> Deploy from a branch -> main / root,
- po opublikowaniu wejdź na wskazany adres HTTPS.
UWAGA: repozytorium publiczne oznacza, że KOD aplikacji jest publiczny. Projekty są przechowywane lokalnie i nie są publikowane w repozytorium.

MODUŁY
- konstruktor dolnej/wiszącej/wysokiej szafki,
- izometryczny schemat i rzut frontu (nie profesjonalny silnik 3D),
- lista formatek, CSV, wydruk / PDF przez systemowy dialog,
- lokalne zapisy projektów, import/eksport .kwd i kopii zbiorczych,
- import dekorów CSV (code;name;collection;color), wyszukiwanie i przypisywanie.

OGRANICZENIA
- Nie zawiera pełnej oficjalnej bazy Kronospan ani tekstur; można zaimportować własną tabelę kodów.
- Nie zawiera profesjonalnych wierceń, okuć, CNC, nestingu, wycen, pomieszczeń czy pełnej kuchni.
- Nie uwzględnia automatycznie grubości oklein, luzów montażowych, naddatków i frezowania pod plecy.
- Dane lokalne przeglądarki mogą zostać usunięte przez system; regularnie eksportuj kopie.
- Oprogramowanie jest prototypem do sprawdzenia przed produkcją.
