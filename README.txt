KORDZIKWOOD Studio 5.9 — Mobile First / Blaty PRO

Nowości: pięć głównych sekcji, dolna nawigacja na iPhone/iPad, wyszukiwarka narzędzi, niezależna biblioteka blatów, import ZIP i zdjęć z katalogów producentów, eksport/import metadanych JSON.

Instalacja: wypakuj WSZYSTKIE pliki do głównego katalogu repozytorium GitHub Pages. Przed aktualizacją zrób kopię projektów. Nie czyść danych Safari.

Uwaga: import ZIP odczytuje obrazy, nie potwierdza automatycznie kodów i wymiarów producenta. Zapisane tekstury są lokalne w IndexedDB; eksport katalogu JSON nie zawiera tekstur. Zachowaj oryginalne ZIP. Obliczenia produkcyjne w poprzednich modułach nadal wymagają weryfikacji.

Testy: składnia JavaScript, poprawność odwołań do zasobów, integralność ZIP. Brak pełnych testów na Safari i iPadOS.
